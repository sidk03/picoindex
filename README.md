This Project is a combination of several smaller project that I will also attach

To run this project do the following:
1) Run build.sh 
2) Run picoindex -> provide the path location to the reference genome file name and the output file name as command line arguments
3) Run picomap -> provide the path location to the suffixarray binary file generated by the picoindex and 
the read file containing a list of sequencing reads to be aligned, a mismatch penalty, gap penalty and an
output file name (both mismatch and gap penalties should be +ve integers that we will convert to -ve)

The output format will be the following:
It starts with the read name and the number of alignments, for each alignment on a seperate line it will
print start position, the score  and the CIGAR string.
